## Vue d'ensemble

Pandelis est un projet web centré sur la gestion de commandes avec un espace d'administration. Le projet met en avant le suivi des commandes, la gestion de statuts et l'organisation du workflow côté back-office.

## Points clés

- **Dashboard admin** : vue de suivi pour piloter les commandes.
- **Workflow de traitement** : statuts de commande, révisions et suppression logique côté interface.
- **Approche produit** : réflexion sur la persistance des métadonnées admin et les limites d'un stockage local.
- **Base exploitable** : structure adaptée à une future évolution vers une vraie persistance serveur.

## Ce que ce projet montre

Ce projet illustre ma capacité à concevoir une interface d'administration utile, à identifier les limites d'une première version, puis à documenter les améliorations techniques à apporter.
